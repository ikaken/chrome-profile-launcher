# Issue #23: セットアップファイルのアイコン変更

## 変更内容
- インストーラー（setup.iss）のアイコンをデフォルトのInno Setupアイコンからプロジェクトのオリジナルアイコン（Assets/app.ico）に変更する。

## 実装手順
1. `installer/setup.iss` を確認し、アイコン定義セクションを特定する。
2. `SetupIconFile` パラメータに適切なパスを設定する。
3. インストーラーを再ビルドし、生成されたファイルを確認する。

## 検証
- ビルドされたインストーラーファイル（exe）のアイコンがオリジナルになっていることを確認する。
