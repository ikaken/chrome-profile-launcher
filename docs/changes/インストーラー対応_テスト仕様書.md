# インストーラー対応 テスト仕様書

## 1. 目的
Inno Setup によって作成されたインストーラーが、意図通りにアプリケーションを配置し、ユーザー環境を設定できることを確認する。

## 2. テスト環境
- OS: Windows 10 または Windows 11 (64bit)
- 状態: .NET 10.0 Desktop Runtime がインストールされている環境および、されていない環境。

## 3. テスト項目

### 3.1 インストールプロセスの確認
| ID | 項目 | 手順 | 期待される結果 |
|:---|:---|:---|:---|
| I-01 | インストーラーの起動 | `ChromeProfileLauncherSetup.exe` を実行する。 | 言語選択（日本語/英語）が表示され、ウィザードが開始されること。 |
| I-02 | インストール先の妥当性 | デフォルトのインストール先を確認する。 | `%LocalAppData%\Programs\Chrome Profile Launcher` 等、ユーザー権限で書き込み可能なパスであること。 |
| I-03 | ファイルの配置 | インストール完了後、インストールフォルダを確認する。 | EXE, DLL, json, Assetsフォルダが正しく配置されていること。 |
| I-04 | ショートカットの作成 | スタートメニューおよびデスクトップ（選択時）を確認する。 | アプリのショートカットが作成され、正しいアイコンが表示されていること。 |

### 3.2 実行・連携確認
| ID | 項目 | 手順 | 期待される結果 |
|:---|:---|:---|:---|
| E-01 | アプリの起動 | ショートカットからアプリを起動する。 | アプリが正常に起動し、Chromeプロファイルが一覧表示されること。 |
| E-02 | 設定の維持 | アプリで設定を変更した後、一度終了して再起動する。 | 設定が維持されていること（%AppData% への保存確認）。 |

### 3.3 アンインストール確認
| ID | 項目 | 手順 | 期待される結果 |
|:---|:---|:---|:---|
| U-01 | アンインストールの実行 | 設定 > アプリ または コントロールパネルから削除する。 | インストールフォルダ内のファイルおよびショートカットが削除されること。 |
| U-02 | ユーザーデータの保持 | アンインストール後、`%AppData%\ChromeProfileLauncher` を確認する。 | `settings.json` が残っており、再インストール時に設定が復元されること。 |

### 3.4 エラー系
| ID | 項目 | 手順 | 期待される結果 |
|:---|:---|:---|:---|
| ERR-01 | ランタイム未検出 | .NET 10.0 がない環境でアプリを実行する。 | ランタイムのダウンロードを促す Windows 標準のダイアログが表示されること。 |
