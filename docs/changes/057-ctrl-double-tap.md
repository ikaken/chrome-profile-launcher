# Issue #57: Ctrlキー2回押しでランチャを表示する

## 概要
Ctrlキーを素早く2回押すことで、ランチャウィンドウを表示・アクティブ化する機能を追加します。
アプリケーションがフォーカスを失っている場合や、タスクトレイに格納されている場合も動作するようにします。

## 変更内容
- `Helpers/KeyboardHookHelper.cs` (新規): 低レベルキーボードフック（LowLevelKeyboardProc）を実装し、グローバルなキー入力を監視します。
- `Services/KeyboardTriggerService.cs` (新規): 入力フックからのキーイベントを受け取り、Ctrlのダブルタップを判定するロジックを実装します。
- `App.xaml.cs`: アプリケーション起動時にサービスを初期化し、ホットキー監視を開始します。

## 技術的詳細
- `SetWindowsHookEx` (WH_KEYBOARD_LL) を使用したグローバルキーフック。
- ダブルタップの判定には `System.Diagnostics.Stopwatch` を使用し、一定時間（例：300ms）以内の連続入力を検知します。
- メモリリーク防止のため、アプリケーション終了時に `UnhookWindowsHookEx` を確実に呼び出します。

## 検証項目
- [ ] 任意のアプリ使用中にCtrlを2回押すとランチャが表示されるか。
- [ ] ランチャが最小化状態から復元されるか。
- [ ] タスクトレイ格納状態から復元されるか。
- [ ] 終了時にフックが正しく解除されるか。
