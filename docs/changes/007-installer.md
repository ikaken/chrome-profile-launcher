# Issue #7 インストーラー対応

## 背景
現在、アプリケーションはポータブルな形式（バイナリ直接配布）を想定しているが、配布サイズが大きくなる可能性がある。また、ユーザーの利便性向上のため、標準的なインストールプロセスが求められている。

## 目的
- アプリケーションの配布サイズ削減（.NETランタイムを含めないフレームワーク依存型への移行）。
- インストーラーによる簡単なセットアップ手順の提供。
- スタートメニューへのショートカット登録。

## 変更内容（予定）
1. ビルド構成の調整（Framework-dependent ビルドを継続）。
2. インストーラー作成ツールの選定：**Inno Setup** を採用。
   - 理由：軽量、スクリプトによる自動化が容易、.NETランタイムのチェックが容易。
3. インストーラースクリプト (`installer/setup.iss`) の作成。
4. ビルド・デプロイ手順のドキュメント化。

## 実装詳細
- インストール先: `%LocalAppData%\Programs\ChromeProfileLauncher` (管理者権限不要なユーザー単位インストールを優先)。
- スタートメニューへの登録。
- デスクトップショートカット（オプション）。
- アンインストーラーの提供。
- .NET 10.0 ランタイムの存在チェック（未検出時はダウンロードページへ誘導）。

## 影響範囲
- ビルド・配布プロセス。
- ユーザーのインストール体験。

## 非対応
- 自動アップデート機能（別Issue #16 で対応予定）。

## 備考
- サイズ削減のため、まずは Framework-dependent での配布を基本とする。
