# Issue #7 インストーラー対応

## 背景
現在、アプリケーションはポータブルな形式（バイナリ直接配布）を想定しているが、配布サイズが大きくなる可能性がある。また、ユーザーの利便性向上のため、標準的なインストールプロセスが求められている。

## 目的
- アプリケーションの配布サイズ削減（.NETランタイムを含めないフレームワーク依存型への移行）。
- インストーラーによる簡単なセットアップ手順の提供。
- スタートメニュー、デスクトップ、およびスタートアップへの登録機能の提供。

## 実施内容
1. **ビルド構成の調整**
   - Framework-dependent ビルドを採用し、配布サイズを約2MBに抑制。
2. **インストーラー作成環境の構築**
   - `winget` を使用して `Inno Setup 6` をインストール。
3. **インストーラースクリプト (`installer/setup.iss`) の作成と改善**
   - ユーザー単位のインストール（管理者権限不要）に対応。
   - Windows設定画面（アプリ一覧）に専用アイコンが表示されるよう `UninstallDisplayIcon` を設定。
   - ショートカット作成時のアクセス拒否エラー (0x80070005) を回避するため、作成先を `{userdesktop}` に修正。
   - インストール時に「スタートアップに登録する」オプションを追加し、PC起動時の自動実行に対応。
4. **検証の実施**
   - サイレントインストール/アンインストールの自動テストを実施し、ファイル配置とクリーンアップが正常であることを確認。
   - インストール後のアプリ起動を確認。

## 実装詳細
- **インストール先**: `%LocalAppData%\Programs\Chrome Profile Launcher`
- **ショートカット**: スタートメニュー、デスクトップ（オプション）、スタートアップ（オプション）
- **ランタイム**: .NET 10.0 Desktop Runtime が必要（未検出時はOSが自動で誘導）

## 影響範囲
- ビルド・配布プロセス。
- ユーザーのインストール体験。

## 備考
- 今後のリリース時は `installer/setup.iss` をコンパイルするだけで最新のインストーラーが生成可能。
