# 変更履歴: Issue #47 インストール直後の言語設定表示修正

## 概要
インストール直後など、設定がデフォルト（自動）の場合に、設定画面の言語選択項目が空欄になる問題を修正します。

## 原因
- アプリの言語設定の初期値が `auto`（自動）になっていたが、設定画面の言語選択 ComboBox に `auto` に対応する項目が定義されていなかった。
- 仕様上、デフォルトの言語は「日本語」であるべきだが、実装上は OS の言語設定を参照する `auto` がデフォルトとなっていた。

## 変更内容
- `Services/SettingsService.cs`: `Language` プロパティの初期値を `auto` から `ja-JP` に変更。
- `ViewModels/SettingsViewModel.cs`: 言語設定の初期化ロジックで、設定がない場合のデフォルト値を `ja-JP` に変更。

## 影響範囲
- 設定画面の言語選択表示（インストール直後）。

## 検証項目
- [ ] 設定ファイルがない状態で起動し、設定画面を開いた際に言語設定が「日本語」と表示されていること。
- [ ] 言語を「English」に変更し、保存・再起動後に正しく反映されること。
- [ ] 設定ファイルを削除して再起動した際、再び「日本語」がデフォルトとして選択されること。
