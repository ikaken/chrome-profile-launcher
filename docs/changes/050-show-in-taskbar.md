# Issue #50: タスクトレイ常駐時もランチャ起動時にはタスクバーに表示する

## 概要
タスクトレイ常駐機能が有効な場合でも、メインウィンドウが表示されている間はタスクバーにアプリアイコンを表示するように変更します。
これにより、隠しオーナーウィンドウの使用を廃止し、ウィンドウ表示のレスポンス改善を図ります。

## 変更内容
- `App.xaml.cs`: 常駐オン時の隠しオーナーウィンドウ作成ロジックを削除。
- `MainWindow.xaml.cs`: `ShowInTaskbar` を設定に関わらず常に `true` （またはデフォルト）で動作するように修正。
- `ViewModels/MainViewModel.cs`: `ShowInTaskbar` プロパティの更新ロジックを修正。

## 検証項目
- [ ] 設定で「タスクトレイに常駐する」がオンの場合、ウィンドウ表示時にタスクバーにアイコンが出るか。
- [ ] ウィンドウを閉じた（非表示にした）時に、タスクバーからアイコンが消えるか。
- [ ] タスクトレイアイコンのダブルクリック等で再表示した時に、タスクバーにアイコンが出るか。
- [ ] 設定がオフの場合、従来通りタスクバーに常に出るか。
