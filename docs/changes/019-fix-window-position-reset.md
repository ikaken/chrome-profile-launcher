# 設定を保存するとウィンドウの位置がリセットされてしまう

## 背景
設定画面での変更を保存する際、`SettingsViewModel` の `SaveCommand` が `SettingsWindow` のウィンドウ位置を正しく永続化していないため、設定画面を開いて保存した後に、メインウィンドウ（あるいはアプリの再起動）の位置設定が初期化または意図しない状態になる事象が報告された。

## 目的
設定保存処理の際に、ウィンドウの Top/Left/Width/Height が正しく `settings.json` に書き込まれるようにし、位置情報が保持されるようにする。

## 変更内容
- `ViewModels/SettingsViewModel.cs` を修正。
- `SaveCommand` の実行時、コマンドの最初で `SaveWindowSettings()` を呼び出し、最新のウィンドウ位置情報を設定ファイルに書き込むようにした。

## 影響範囲
- アプリケーション全体のウィンドウ位置設定永続化機能。

## 非対応
- 特になし。

## 備考
- テストコードにより、設定保存の整合性が担保されていることを確認済み。
