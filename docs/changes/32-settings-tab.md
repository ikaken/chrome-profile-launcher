# 設定画面のタブ分け

## 背景 / 目的
設定画面のスイッチ類が増えてきたため、プロファイルの並び替え画面と、アプリ各種設定のスイッチ画面をタブで切り替えられるようにします。これにより、UIの整理と操作性・視認性の向上を図りました。

## 変更内容
- [x] 設定画面（`Views/SettingsWindow.xaml`）に TabControl を導入し、タブ切り替えUIを構成
- [x] 「プロファイル管理」と「アプリ設定」のタブを定義し、それぞれの要素を適切に再配置
  - **プロファイル管理**: 既存のプロファイル一覧 `ListBox` （ドラッグ＆ドロップ並び替え機能付き）をそのまま配置
  - **アプリ設定**: 「スタートアップ時に起動」「タスクトレイに常駐」「アップデートを確認」の各種設定コントロールを説明付きのカード風 UI (Border) として綺麗に再配置
- [x] ダークモードデザインと調和するモダンなカスタムスタイル `ModernTabControlStyle` および `ModernTabItemStyle` を追加
- [x] 設定画面のデフォルトの高さ（Height）を450から550に調整し、初回起動時やリセット時にすべての項目が綺麗に収まるよう調整 (`ViewModels/SettingsViewModel.cs`)

## 影響範囲
- `Views/SettingsWindow.xaml`
- `ViewModels/SettingsViewModel.cs`
- ユーザーインターフェース (設定画面)

## 備考
- ドラッグ＆ドロップ操作やバインディングへの悪影響はなく、機能は完全に保持した状態で視認性が大幅に向上しました。
