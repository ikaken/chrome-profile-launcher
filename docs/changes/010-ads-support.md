# Issue #10 広告表示対応

- 作成日: 2026-05-14
- 概要: ランチャー画面下部（Settingsボタン左側）への広告バナー配置および表示制御ロジックの実装。

## 実装内容
- **UI**: `MainWindow.xaml` に `WebView2` コントロールを配置。設定ボタン左側に配置し、境界線・マージン・ラベルで視覚的に分離。
- **制御**: `AdHelper.cs` を作成。初期表示遅延（2秒）を実装し、表示状態を管理。
- **ViewModel**: `MainViewModel.cs` に `IsAdVisible` プロパティを追加し、バインディング。
- **検証**: テスト用 URL (bing.com) を使用し、WebView2 が正常にコンテンツをロードできることを確認済み。

## 検証結果
- レイアウトは要件通り、設定ボタンから 12px の間隔を確保。
- WebView2 による Web コンテンツの表示を確認。
- 実運用時は、ここへ広告配信サービスのタグを含む URL を割り当てることで表示可能。
