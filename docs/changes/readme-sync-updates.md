# READMEの記述および対応環境の更新

## 背景 / 目的
日本語版READMEでのフォーカス制御に関する注記と対応環境の追加に伴い、見出しにアイコン（💻）を付与し、さらにそれらの内容を英語版（English）にも漏れなく同期する。あわせて開発者向け情報として、アプリが使用しているアーキテクチャおよび主要な技術スタックについての日英両セクションへの追記を行う。また、プロジェクト構造およびドキュメントで参照している各ディレクトリ名に対して、ディレクトリへの相対リンクを設定する。さらに、リポジトリのステータスや使用技術を視覚的に伝えるため、冒頭にShields.ioのバッジ群を追加する。応援方法（サポート）に「スター（Star）を付ける」を追加し、GitHub Star のソーシャルバッジを追加する。現在のコードで未実装の「表示名の変更」機能についての記述を削除する。最後に、どのようなユーザー向けのアプリケーションなのかを明確にするため、最初の説明部分に対象ペルソナ（複数プロファイルを使い分ける人）についての紹介を追記する。

## 変更内容
- 英語版の「Launch & Focus Control」に「(Only for windows launched by the launcher)」の但し書きを追記。
- 英語版に「💻 System Requirements」セクションを追加。
- 日本語版の「対応環境」見出しを「💻 対応環境」に変更。
- 英語版および日本語版の「開発者向け情報（For Developers）」に、アプリケーションの「アーキテクチャ / 技術スタック（Architecture & Tech Stack）」の要約を追記。
- 英語版および日本語版の「プロジェクト構造（Project Structure）」における `Models/`、`ViewModels/`、`Views/`、`Services/`、`Helpers/` ディレクトリ名、および「ドキュメント（Documentation）」の `docs/` にて、実際のディレクトリへのマークダウン相対リンクを設定。
- READMEの最上部に、`GitHub Release` (最新正規リリース)、`Platform` (Windows)、`Language` (C#)、`Runtime` (.NET 10)、`License` (MIT) の各種バッジを追加。
- 英語版および日本語版の応援セクション（Support / Sponsor this Project）に「スター（Star）を付ける」の説明と、GitHub Star のソーシャルバッジを追加。
- 英語版および日本語版の「プロファイルカスタマイズ（Profile Customization）」項目から、現在未実装の「表示名の変更（Rename）」機能に関する記述を削除。
- 英語版および日本語版の導入文（紹介テキスト）の直後に、「💡 Who is this for? / こんな方におすすめ」セクションを追加し、日常的に複数のChromeプロファイルを使い分けるユーザーに最適である旨を記載。
