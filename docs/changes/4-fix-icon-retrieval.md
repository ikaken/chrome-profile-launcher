# #4 セキュリティソフトに対応したアイコンの取得

## 背景
セキュリティソフト（カスペルスキー等）の保護機能が有効な場合、Chromeのプロファイルフォルダ内にある `Google Profile Picture.png` へのアクセスが制限され、アプリ上でアイコンが表示されない（またはデフォルトアイコンにフォールバックされない）問題がある。

## 目的
アイコンファイルが存在しても読み取れない場合に、ICOファイル、さらには Chrome 本体のアイコンへ順次フォールバックする仕組みを構築し、常に適切なアイコンが表示されるようにする。

## 変更内容
1. `IFileSystem` に読み取り可能性チェック (`CanReadFile`) を追加。
2. `IconService` の取得ロジックを更新（PNG -> ICO -> chrome.exe）。
3. `chrome.exe` からアイコンを抽出するための `ValueConverter` を導入。
4. XAML のバインディングを更新。

## 影響範囲
- アイコン表示部分（メインウィンドウ、設定ウィンドウ）

## 非対応
- 特になし

## 備考
- `Assets/app.ico` はランチャー自体のアイコンとして維持し、プロファイルのフォールバックには使用しない。
