# Chromeプロファイルランチャ - タスクトレイ常駐機能 仕様書

## 1. 概要
本機能は、ユーザーがアプリケーションの起動・終了、およびバックグラウンド実行を効率的に管理できるようにするタスクトレイ常駐機能です。設定項目「Stay in Task Tray」によって、アプリケーションの表示・終了挙動を統合的に制御します。

## 2. 仕様定義

| 設定項目: **Stay in Task Tray** | **ON (常駐する)** | **OFF (常駐しない)** |
| :--- | :--- | :--- |
| **タスクバー表示** | **表示（ウィンドウ表示中のみ）** | 表示 |
| **タスクトレイアイコン** | 表示 | 非表示 |
| **閉じるボタン (×)** | ウィンドウを非表示にし、トレイへ格納（終了しない） | アプリケーションを終了する |
| **最小化ボタン** | **タスクバーへ最小化（OS標準挙動）** | タスクバーへ最小化 |
| **復元方法** | タスクバーまたはトレイアイコンをクリック | タスクバーのアイコンをクリック |
| **二重起動時の挙動** | 既存インスタンスを前面に復元 | 既存インスタンスを前面に復元 |

---

## 3. 実装詳細
*   **動的制御**: 設定変更時、アプリケーションを再起動することなくタスクバー表示とトレイアイコンの生成/削除を動的に実行。
*   **タスクバー制御 (Issue #50)**: ウィンドウが表示されている間は常にタスクバーにアイコンを表示する。ウィンドウが非表示（Collapsed）の際は、OSの標準的な挙動によりタスクバーから自動的に消去される。
*   **挙動の差別化**: 
    - **最小化**: OS標準の挙動を優先し、タスクバーにアイコンを残す。
    - **閉じる**: 常駐機能としてウィンドウを非表示（Collapsed）にし、タスクバーから消去する。
*   **シンプル化**: 常駐オン時にタスクバーを強制的に隠すための「隠しオーナーウィンドウ」を廃止し、表示レスポンスの向上とコードの簡素化を図った。
*   **終了制御**: 常駐オフ時は `Application.Current.Shutdown()` を呼び出し、プロセスを確実に終了させる。
