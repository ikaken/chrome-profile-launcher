# タスクトレイ常駐機能 テスト仕様書

## 1. テスト環境
- OS: Windows 10/11
- ChromeProfileLauncher 最新ビルド
- ログ出力先: `%APPDATA%\ChromeProfileLauncher\debug.log`

## 2. テストケース

| No | テスト項目 | 手順 | 期待結果 (UI/挙動) | 期待結果 (ログ出力例) |
| :--- | :--- | :--- | :--- | :--- |
| 1 | **常駐 ON 起動** | 設定で ON にして起動 | タスクトレイにアイコンあり、タスクバー非表示 | `Configured for task tray`, `InitializeTaskbarIcon`... |
| 2 | **常駐 ON ×ボタン** | ×ボタン押下 | ウィンドウ非表示、常駐継続 | `Window_Closing: EnableTaskTray=True` |
| 3 | **常駐 ON トレイ復元** | アイコンをシングルクリック | 最小化解除し、ウィンドウ表示 | `ShowWindowCommand executed`, `Restoring window` |
| 4 | **常駐 OFF 起動** | 設定で OFF にして起動 | トレイアイコンなし、タスクバー表示 | `Configured for task bar`, `Skipping TaskTray` |
| 5 | **常駐 OFF ×ボタン** | ×ボタン押下 | アプリケーションが完全に終了 | `Window_Closing: EnableTaskTray=False`, `Terminating` |
| 6 | **設定切り替え ON→OFF** | 動作中に設定変更 | アイコン即消滅、タスクバー出現 | `EnableTaskTray changed to: False`, `Disabling TaskTray icon` |
| 7 | **設定切り替え OFF→ON** | 動作中に設定変更 | タスクバーから消え、トレイにアイコン出現 | `EnableTaskTray changed to: True`, `Enabling TaskTray icon` |
| 8 | **二重起動** | アプリ起動状態で再度起動 | 新ウィンドウなし、既存が最前面復元 | `Activating MainWindow requested via IPC` |
