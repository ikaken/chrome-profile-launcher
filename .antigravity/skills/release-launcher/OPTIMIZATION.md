# Release Launcher: Workload Optimization Guidelines

リリースプロセスにおける各種検証やドキュメントの更新作業を効率化するため、Antigravityエージェントはサブエージェントを動的に活用して作業量を分散させることができます。

## 1. ⚙️ Actions監視とバックグラウンド検証（Step 3）
* **手法**: `self` または専用の `test-runner` サブエージェントにActions監視を依頼する。
* **役割**: GitHub Actions（`release.yml`）のジョブ実行完了を待機し、定期的にログやアセット生成結果を確認。
* **メリット**: 監視中にメインエージェントの会話スレッドが占有されるのを防ぎ、応答性を維持します。

## 2. 📖 READMEおよびリリースドキュメントの並行更新（Step 4, 5）
* **手法**: ドキュメント担当のサブエージェントを起動するか、並行して処理を行う。
* **役割**: `README.md` のダウンロードリンク書き換えの準備や、リリースノートに記載する変更サマリー（ドラフト作成）などを並行して作成・整理。
* **メリット**: テキストやドキュメントの準備作業をサブエージェントに並行して分散処理させることで、メインエージェントは全体的なガバナンスとユーザーとの合意形成に専念できます。
