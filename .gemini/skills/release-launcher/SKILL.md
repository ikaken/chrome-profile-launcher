# Release Launcher

このスキルは、Chrome Profile Launcher のリリース作業をガイドします。

## リリースフローの開始

リリース作業を開始するには、以下のコマンドを Gemini CLI で入力してください。

`/skill release-launcher`

Gemini は以下のフローを順番に案内します。

1. **事前準備の確認**: バージョン番号の決定と、現在のコードがメインブランチにあることを確認します。
2. **タグの作成とプッシュ**: ユーザーの指定したバージョンでタグを作成し、リモートへプッシュします。
3. **GitHub Actions の監視**: リリースの実行状況を監視し、成功したか報告します。
4. **リリースノートの作成**: GitHub Releases の編集URLを案内し、リリースノートの記述を支援します。

## 注意事項

- 本スキルはメインブランチに対してタグを打つことを前提としています。
- リリース前に必ずビルドが正常に完了することを確認してください。
