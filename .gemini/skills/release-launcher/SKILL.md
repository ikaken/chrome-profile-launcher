# Release Launcher (Automated Workflow)

このスキルは、GitHub Actionsを活用した Chrome Profile Launcher の自動リリース作業をガイドします。

## 🚀 リリースフロー

本プロジェクトは `v*` タグがプッシュされると GitHub Actions が起動し、自動的にインストーラーのビルド・パッケージング・リリース作成を行います。

1. **事前準備**: 
    - `git status` で変更がないことを確認し、必要に応じてコミットする。
    - バージョン番号を決定する（例: `v0.1.5-beta`）。
2. **タグ付け**:
    - `git tag <バージョン番号>` でタグを作成する。
3. **プッシュ**:
    - `git push origin <バージョン番号>` でタグをプッシュする。
4. **アクション監視**:
    - GitHub Actions の実行状況を監視し、成功を報告する。
5. **リリースノート編集**:
    - 作成されたリリースの詳細をGitHub上で編集する。

---

## ⚠️ 注意事項
- 手動でのビルドは不要です。Actionsが最新のソースコードをベースにパッケージングを行います。
- リリース前に、必ずメインブランチが最新状態であることを確認してください。
